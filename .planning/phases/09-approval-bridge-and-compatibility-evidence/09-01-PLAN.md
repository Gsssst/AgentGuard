<objective>
Implement the approval bridge contract and replay-safe GuardedToolNode orchestration for a multi-tool batch.

Purpose: make LangGraph the sole interrupt/checkpoint owner while preserving AgentGuard's permission, digest, lock, timeout, retry, audit, failure-isolation, and ordering boundaries.
Output: public approval DTO/helpers, a single-interrupt adapter path, and deterministic unit coverage.
</objective>

<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| AIMessage/resume input → adapter | Tool names, arguments, IDs and approval decisions are untrusted model/reviewer data. |
| Adapter → Runtime/tool | Approved calls cross into side-effecting functions and resource locks. |
| Adapter → LangGraph interrupt payload | Payload may be shown to a human and persisted by the graph checkpointer. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-09-01 | Tampering | resume decision/digest | mitigate | Bind each decision to original tool_call_id, run_id, input index, capabilities and unredacted canonical args; mismatch rejects only that call. |
| T-09-02 | Information disclosure | approval projection | mitigate | Reuse recursive redact() and test password/token/authorization/private-key nesting; never serialize raw args or lock internals. |
| T-09-03 | Repudiation | approval/audit events | mitigate | Preserve actor, reason and digest per decision through Runtime event boundary. |
| T-09-04 | Denial of service | pending lock/interrupt | mitigate | Do not hold locks while interrupting; enforce existing Runtime lock/timeout/concurrency limits after approval. |
| T-09-SC | Tampering | dependency/runtime assumptions | mitigate | No new package; Plan 02 verifies the declared optional packages and public APIs in a clean environment. |
</threat_model>
