<threat_model>
## Assets

- Confidential tool arguments/results, credentials, approval metadata, exception details, and local paths.
- Integrity of the immutable `agentguard.event.v1` schema and event-type semantics.
- Availability of the normalizer when given adversarial or malformed tool-owned objects.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Tool/adapter value -> safety projector | Arbitrary nested or user-defined Python values become telemetry candidates. |
| Legacy RuntimeEvent.data -> v1 normalizer | Free-form internal facts cross into a future persistence/streaming contract. |
| v1 model -> downstream phases | Phase 12-14 will trust the accepted envelope, so unsafe data must be rejected here. |

## Abuse Cases and Mitigations

| Threat ID | STRIDE | Abuse case | Severity | Disposition | Concrete mitigation |
|---|---|---|---|---|---|
| T-11-01 | Information Disclosure | A nested token, exception message, stack, path, or approval reason is copied into an envelope. | HIGH | mitigate | D-16..D-18 recursive marker redaction, bounded preview wrappers, exact payload allowlists, and fixed summaries; adversarial tests assert forbidden sentinel strings are absent. |
| T-11-02 | Denial of Service | Deep/wide/cyclic values or hostile coercion exhaust resources or run attacker code. | HIGH | mitigate | Depth/item/string/node budgets, cycle detection, JSON primitives only, no `str`/`repr`, and strict JSON serialization tests. |
| T-11-03 | Tampering | Unknown keys or a source-controlled sequence/status alter public semantics. | HIGH | mitigate | Closed EventType registry, exact key validation, Collector-reserved sequence, deterministic status mapping, and only named source_sequence evidence. |
| T-11-04 | Spoofing | A nullable/duplicate external tool_call_id is treated as the internal logical identity. | MEDIUM | mitigate | Separate validated EventCorrelation.call_id from preserved nullable tool_call_id and enforce tool lifecycle correlation. |

All HIGH threats have blocking automated mitigations in this plan; no unresolved HIGH risk remains.
</threat_model>
