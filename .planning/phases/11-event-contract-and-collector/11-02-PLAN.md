<threat_model>
## Assets

- Integrity and privacy of call_id, tool_call_id, batch_id, and run_id relationships.
- Availability and original semantics of Runtime tool execution, retries, locks, approvals, and checkpoint resume.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Caller/adapter -> Runtime execution API | Caller-provided run, batch, external call, and approval data enter producer logic. |
| ToolExecutor callback -> Runtime source event | Concurrent attempt/retry facts receive correlation owned by Runtime. |
| Checkpoint resume -> replayed tool lifecycle | Persisted non-secret logical coordinates recreate correlation after a crash. |

## Abuse Cases and Mitigations

| Threat ID | STRIDE | Abuse case | Severity | Disposition | Concrete mitigation |
|---|---|---|---|---|---|
| T-11-05 | Spoofing | Duplicate/malformed external IDs collapse distinct logical calls. | HIGH | mitigate | Runtime-generated internal call_id is authoritative; external ID remains nullable evidence; per-batch uniqueness tests ignore external IDs. |
| T-11-06 | Tampering/Repudiation | Retries or resume silently receive new IDs, or batch_id overwrites run_id. | HIGH | mitigate | Immutable correlation closed over callbacks, deterministic non-secret replay coordinate, separate batch emitter arguments, and lifecycle grouping tests. |
| T-11-07 | Information Disclosure | IDs encode arguments, errors, actor/reason, or results. | HIGH | mitigate | UUID4/UUID5 uses only fixed namespace plus run/step/batch/index coordinates; forbidden secret sentinel tests cover all generators. |
| T-11-08 | Denial of Service | Correlation changes bypass timeout/lock/retry isolation or duplicate lifecycle emission. | MEDIUM | mitigate | Preserve ToolExecutor/lock control flow, add only keyword-compatible seams, suppress only subset batch boundaries, and run existing concurrency/recovery suites. |

All HIGH threats have blocking automated mitigations in this plan; no unresolved HIGH risk remains.
</threat_model>
