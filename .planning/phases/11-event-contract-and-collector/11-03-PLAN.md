<threat_model>
## Assets

- Per-run event ordering, terminal identity, and summary integrity.
- Process memory and Runtime availability under malformed/high-volume input.
- Confidentiality of rejected event data and internal collector failures.

## Trust Boundaries

| Boundary | Description |
|---|---|
| RuntimeEvent -> EventCollector | Concurrent free-form source facts enter a process-local authoritative timeline. |
| Collector lock -> public snapshots | Mutable internal state is exposed to future API/persistence consumers. |
| Validation failure -> diagnostics | Rejected untrusted data must become observable without becoming a second event stream. |

## Abuse Cases and Mitigations

| Threat ID | STRIDE | Abuse case | Severity | Disposition | Concrete mitigation |
|---|---|---|---|---|---|
| T-11-09 | Tampering/Repudiation | Concurrent/source-controlled events create duplicate sequence, reorder history, or resurrect terminal runs. | HIGH | mitigate | Single minimal `threading.Lock` transaction, Collector-only sequence, explicit terminal check/state table, and barrier-based invariants. |
| T-11-10 | Denial of Service | Events/runs/diagnostics grow unbounded or malformed collection interrupts the Agent. | HIGH | mitigate | Positive fixed limits, bounded deques, safe capacity rejection, and fail-open emit/accept tests. |
| T-11-11 | Information Disclosure | Rejection diagnostics include raw payload, stack, or exception message. | HIGH | mitigate | Stable diagnostic codes/categories only, bounded labels, no str(exc)/candidate retention, and sentinel-absence tests. |
| T-11-12 | Denial of Service | External code is called under the Collector lock and re-enters/deadlocks. | HIGH | mitigate | Clock/normalization outside lock, no callback/downstream sink/public formatter in critical section, code-structure assertion plus concurrency completion test. |
| T-11-13 | Tampering | A consumer mutates returned timelines or summaries. | MEDIUM | mitigate | Frozen dataclasses, tuple snapshots, defensive nested copies, and mutation tests. |

All HIGH threats have blocking automated mitigations in this plan; no unresolved HIGH risk remains.
</threat_model>
