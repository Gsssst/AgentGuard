<threat_model>
## Assets

- Integrity of approval/retry/result correlation across LangGraph checkpoint resume.
- Confidentiality of model-supplied arguments, approval data, tool failures, and persisted prepared state.
- Compatibility and availability of GuardedToolNode, MessagesState reducers, and optional dependency isolation.

## Trust Boundaries

| Boundary | Description |
|---|---|
| AIMessage tool_calls -> GuardedToolNode.prepare | Untrusted external names, IDs, and arguments are parsed and partitioned. |
| LangGraph checkpoint/resume payload -> approval | Persisted/untrusted per-call decisions and prepared context re-enter execution. |
| Adapter early return -> Runtime EventSink | Rejections that invoke no tool still need safe correlated observability. |

## Abuse Cases and Mitigations

| Threat ID | STRIDE | Abuse case | Severity | Disposition | Concrete mitigation |
|---|---|---|---|---|---|
| T-11-14 | Spoofing/Repudiation | Duplicate external IDs or resume data attach approval/result events to the wrong logical call. | HIGH | mitigate | Per-index internal call_id, persisted correlation context, existing digest-bound fail-closed resume, and exact lifecycle grouping tests. |
| T-11-15 | Information Disclosure | Invalid tool/approval/error branches expose raw arguments, reasons, digests, exception details, or paths. | HIGH | mitigate | Runtime framework-event seam plus Plan 01 allowlists/fixed summaries; malicious sentinel assertions span envelopes and diagnostics. |
| T-11-16 | Tampering | Mixed direct/pending subsets create duplicate batch boundaries or replay direct side effects. | HIGH | mitigate | One original batch context, subset lifecycle suppression, prepared consumed state, invocation counters, and public MessagesState/MemorySaver regression. |
| T-11-17 | Denial of Service | One malformed/failed call cancels sibling tool execution or Collector failure breaks the graph. | HIGH | mitigate | Existing per-call normalization/failure isolation, gather semantics, fail-open Collector, and mixed fault-matrix tests. |
| T-11-18 | Elevation of Privilege | Observability emission bypasses permission, approval digest, resource lock, timeout, or retry checks. | HIGH | mitigate | Framework seam emits facts only; actual tools continue exclusively through Runtime.execute_explicit_batch and existing guards; regression tests assert control paths. |

All HIGH threats have blocking automated mitigations in this plan; no unresolved HIGH risk remains.
</threat_model>
