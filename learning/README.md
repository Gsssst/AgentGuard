# Learning Notes

These notes are evidence records, not AI-generated summaries. Each note should be updated after the corresponding implementation, failure injection, tests, and mature-system comparison.

Learning notes are maintained in two language versions:

- `learning/zh-CN/` — primary learning and interview-review version.
- `learning/en/` — open-source collaboration version.

Both versions must describe the same verified facts. The English version must never turn a planned or partially verified capability into a completed claim.

The root-level note is kept as a compatibility entry point and links to both language versions.

Suggested template:

```markdown
# Problem
# Why it matters
# My first design
# Alternatives
# Failure modes
# What broke
# Debug process
# How mature systems solve it
# Final design
# Trade-offs
# Interview questions I can now answer
```
